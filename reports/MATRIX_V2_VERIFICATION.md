# Matrix loop v2 验收

日期：2026-11-21。依据：[机器可读结果](matrix_loop_v2_validation.json)。

## 修正范围

1. 原C/N/O单原子取代保持nH2不变且增加质量，因此其理论H2质量分数只能下降。新加入贫氢态乙烯基/富氢态乙基、贫氢态炔基/富氢态乙基两类成对操作，分别增加1和2个形式H2当量。原有母核及两态重原子连通关系保持，合法性和计量逐个验证。
2. 父代由所有已占格按最少访问次数选择，同次数按身份哈希稳定打破平局。操作预算按父代/操作类型轮转分配，取消固定格编号前缀和操作枚举前缀。固定32父代的回归测试验证三轮12父代预算覆盖全部父代，并验证输入顺序反转不改变结果。
3. 8个种子先经与子代完全相同的critic提示词、文献策略与参数评分，再进入档案。离线模式则两者都明确使用中性占位。评分协议SHA256在种子与子代记录中一致。
4. UCB保留45维结构特征，附加格是否为空、当前格质量、总体占格比例三个前更新状态。加截距为49个系数，更新使用评价前保存的上下文；奖励仍为实际入档或质量提升。这是经验性上下文模型，不宣称具备经典静态线性模型的遗憾界。

## 验证结果

- 六项回归测试全部通过：H2计量及母核保持、操作顺序独立性、父代覆盖、状态上下文、五折GNN加载、CPU/GPU编辑与UCB一致性。
- 修复版真实API三轮共8次HTTP200：8个种子先评，再评价12个子代；占格8→11，分子银行20对。该轨迹不是相对旧策略的性能比较。
- 验证菜单中，乙烯基/乙基47次、炔基/乙基43次有效操作的H2增量分别全部为1、2；其中31次和43次形式容量增加。跨轮可能重复，不能作为74个独立新分子的发现统计。
- 关闭原本地项目数据读取后，CPU独立运行两轮成功，零API调用。此模式只证明示例包可运行，不冒充完整数据评价。
- 五折原权重总计4483710字节，逐文件SHA256与原模型相同。架构、归一化及训练摘要一并提供，未重训。

## 保留的研究边界

算子集有界，尚未移植每一种旧GA操作；新侧链的H2计量不代表实际可逆性。GNN、SP及SA为搜索工具，不是独立物理真值。当前文献库仅6条旧记录，证据适用性基准尚未建立。初始8→11占格与单次运行不能证明机制或优化优势。

旧GPU吞吐数据属于此前明确范围的驻留核实验；v2增加状态上下文，本报告不将旧数字包装成v2整系统加速。新GNN的原分组OOF指标保留原验证限制，未宣称严格scaffold外推。
